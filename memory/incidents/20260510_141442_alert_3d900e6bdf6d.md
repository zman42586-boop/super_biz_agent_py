## 3️⃣ 根因分析

### 3.1 根因定位

> **根因：CPU 高负载运行导致 CCD 核心温度持续偏高**

**判断依据：**

1. **全 CPU 传感器联动升高** — Core (Tctl/Tdie) 达到 **63.4°C**，所有 CCD 传感器（CCD1、CCD2、CCDs Max、CCDs Average）均处于 **56°C~58°C** 高位，说明是整个 CPU 封装发热，而非单一传感器故障。

2. **温度波动特征符合计算负载模式** — 数据点显示温度在 57°C~70.8°C 之间剧烈波动，两次尖峰（67.1°C、70.8°C）间隔约 38 秒，符合 **周期性高负载任务（如编译、渲染、科学计算）** 的典型温度曲线。

3. **内存和 GPU 温度正常** — DIMM #0 为 47.5°C，GPU 传感器正常，排除了 **散热系统整体失效**（如风扇停转、空调故障）的可能性，因为如果是整体散热问题，内存和 GPU 温度也会同步升高。

4. **温度未达到降频阈值** — 当前最高 70.8°C，对于现代 CPU 而言尚未触发降频保护（通常 95°C~105°C），说明 **散热系统仍在工作**，但散热能力不足以应对当前负载。

### 3.2 排除项

| 可能原因 | 排除依据 |
|---------|---------|
| ❌ 传感器故障 | 所有 CPU 传感器读数一致偏高，非单一异常 |
| ❌ 散热系统整体失效 | 内存/GPU 温度正常，散热系统仍在运行 |
| ❌ 环境温度过高 | 仅 CPU 区域温度异常，非全局性升温 |
| ❌ 病毒/挖矿程序 | 无法完全排除，需进一步检查进程 |
