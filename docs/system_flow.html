1 · 系统全景总览

监控 Agent 是独立进程，与 FastAPI 通过 Webhook 解耦；HarnessWorker 把诊断变成 MySQL 持久化作业；Agent 执行时按需调用 MCP 工具和 Milvus 检索。

2 · 监控与告警链路（lhm_alert_agent）

4 · RAG 混合检索管线

Dense + BM25 并行召回 → RRF 融合 → 置信度决定是否改写重试 / 重排。语义证据不足时明确拒答"原因未确定"，而不是编造根因。阈值：low 0.35 / high 0.55。

5 · Agent Harness 持久化执行（v1 新增）

MySQL 是唯一事实源：作业状态、步骤、工具调用、SSE 事件全部落库。Worker 崩溃后 lease 过期 → 其他 Worker 认领并从 state_json 恢复；幂等键命中时直接复用已成功的结果，不重复执行。

6 · 分层记忆（Hot / Cold）
