# 高 CPU 负载诊断 Skill

适用于：CPU 飙高、某进程占用 CPU 过高、整机 load 异常等 OnCall / AIOps 场景。

## 推荐步骤

1. 使用 Monitor MCP 的 **CPU / 进程相关工具**（如 `get_cpu_metrics`、`get_process_info` 等）查询当前 CPU 使用率最高的进程与服务，识别异常进程名与 PID。
2. 使用 **search_log**（本地 `logs/app_*.log`）或 CLS MCP 查询与上述进程/服务相关的错误、异常、超时、GC、线程池耗尽等日志证据。
3. 结合进程详情（线程数、内存、启动时间、命令行等）判断瓶颈类型：计算密集、锁竞争、频繁 GC、死循环或外部依赖拖慢等。
4. 综合指标与日志生成**根因结论**与**可执行的处理建议**（限流、重启、扩容、代码/配置优化、临时规避措施等）。

## 规划时请遵守

- 制定计划时可在步骤描述中显式带上 Skill 标识 `CPUHighLoadDiagnosis`，便于执行阶段识别。
- 每一步应写明拟调用的工具名称及必要参数思路；严禁编造未通过工具获取的数据。
